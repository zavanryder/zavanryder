# Jake Evans

Offensive security researcher exploring adversarial behavior in complex systems, including cloud infrastructure, distributed platforms, and emerging AI systems.

For more than 25 years I’ve worked in offensive security, focusing on discovering novel attack paths, modeling adversaries, and building tooling that helps security teams understand how real attackers operate.

My current research interests focus on the intersection of **offensive security and AI systems**, particularly how LLMs and agentic systems introduce new classes of attack surfaces.

---

## Research Interests

- AI system security
- Adversarial testing of LLM agents
- Prompt injection and instruction hierarchy attacks
- Tool misuse and agent privilege escalation
- Detection artifact modeling
- Offensive security automation

## Philosophy

Effective security research requires thinking like an adversary:

- explore assumptions
- model creative attackers
- test systems in unexpected ways

The most interesting failures often emerge from **interactions between systems**, not just individual bugs.
